# Design System

Base vendor-neutral para qualquer interface gerada pelo pacote.

| Pasta | Conteúdo |
|---|---|
| `tokens/` | cores, tipografia, espaçamento — variáveis sem valor de fornecedor |
| `components/` | primitivas (botão, input, card) em cima dos tokens |
| `guidelines/` | regras de acessibilidade, responsividade e hierarquia |

Perfis (Profox, legado) podem sobrescrever tokens, nunca as regras de acessibilidade. Detalhamento na FASE 6.
